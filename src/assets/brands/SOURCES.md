# Brand logo sources

Logos are bundled with the app so they work offline. Nothing is
fetched at runtime and no expense data is sent anywhere.

All logos are trademarks of their respective owners and are used
only to identify the merchant beside an expense, in a personal app.
Wikipedia/Wikimedia files list the license shown on their file page
(`Public domain` is usually a simple-text-logo exemption; `Fair use`
means a non-free logo). Raster files from Wikipedia are its 250px PNG
renders of the source file.

To add a brand: save `<id>.png` or `<id>.svg` here, add a row
below, and add the entry in `src/utils/brands.js`.
